# Scrap Derby

Three.js 차량 배틀로얄 io 게임, 끝없는 스테이지 진행 (솔로 플레이). 파일 하나(`index.html`), 빌드 없음.

## 스테이지 (무한)

- **한 스테이지 = 배틀로얄 한 판.** 원형으로 줄 선 차들이 3, 2, 1, GO로 동시에 출발하고, 바깥 바닥이 단계적으로 무너집니다(무너지기 8초 전 빨간 경고). 마지막 1대가 되면 **CLEAR**, 다음 스테이지가 열립니다. 부서지거나 떨어지면 같은 스테이지 재도전.
- **스테이지가 오를수록**
  | 항목 | STAGE 1 | 증가 방식 |
  | --- | --- | --- |
  | 출전 차량 | 7대 | 스테이지당 +0.8대, STAGE 11부터 15대 |
  | 봇 공격성 | ×1.0 | +5%/스테이지 (최대 ×1.8), 도주 성향은 감소 |
  | 봇 시작 적재량 | 0~30 kg | +25 kg/스테이지 (최대 600) |
  | 바닥 붕괴 대기 | 24초 | −3%/스테이지 (최대 −45%) |
  | 아레나 반지름 | 102 | 차 수에 비례 (80~125) |
- **보스 스테이지:** 5, 10, 15…에는 거대한 "보스 크러셔"(900 + 80×스테이지 kg)가 나와 난이도와 상관없이 나를 노립니다.
- **별:** 우승 1개, 2대 이상 격파 2개, 5대 이상 격파 3개. 깬 스테이지는 메인 화면의 스테이지 길에서 다시 골라 별을 모을 수 있습니다.
- **경험치:** 순위(참가 10 + 한 단계 위마다 +10), 클리어(60 + 10×스테이지), 격파, 고철, 별. 레벨이 오르면 차 색이 해금됩니다 (LV 2, 3, 4, 5, 6, 8, 10).
- **격파 연출:** 슬로모션 히트스톱, 카메라 펀치, 화면 플래시, 콤보 배너(더블/트리플/쿼드라 크래시, 폐차장의 왕), 효과음, 진동.

## HUD

| 위치 | 내용 |
| --- | --- |
| 왼쪽 위 | 적재량(kg), 격파 수, 소리 |
| 가운데 위 | 스테이지 번호, 생존 대수와 진행 바, 바닥 붕괴 타이머 (경고 시 빨간색) |
| 오른쪽 위 | 미니맵 (현재 경계 + 다음 경계 점선) |
| 가운데 아래 | 차체(왼쪽으로 차는 바, 피격 시 흰 잔상) · 속도 · 니트로(오른쪽으로 차는 바) |

## 아이템 상자

아레나에 최대 9개까지 생기고, 밟는 즉시 효과가 끝납니다(지속 효과나 무적 없음). 봇도 근처 상자를 노립니다.

| 상자 | 효과 | 등장 비율 |
| --- | --- | --- |
| 니트로 충전 (파랑) | 니트로 100% 충전 | 34% |
| 고철 더미 (주황) | +60 kg 성장 | 38% |
| 수리 키트 (초록) | 차체 내구도 전부 회복 | 18% |
| 황금 고철 (금색) | +180 kg 대박 성장 | 10% |

## 시작 화면

io 게임식 메인 화면: 뒤에서 실제 아레나가 돌아가고, 위에는 레벨과 경험치 바 · 모은 별 · 소리 버튼, 가운데 로고와 3D 차고(좌우 화살표나 스와이프로 색 변경, 잠긴 색은 해금 레벨 표시), 스테이지 길(깬 곳은 별 표시, 보스 스테이지는 점선과 BOSS), 닉네임, PLAY, 난이도, 아래엔 돌아가는 팁.
스테이지가 끝나면 CLEAR/FAILED, 별, 경험치 내역, 레벨 바가 나오고 "다음 스테이지 도전" · "다시 하기" · "차고로"를 고릅니다.

## 난이도

시작 화면과 결과 화면에서 고릅니다. 기본값은 **쉬움**이고 선택은 브라우저에 저장됩니다.

| | 쉬움 | 보통 | 어려움 |
| --- | --- | --- | --- |
| 봇 시작 적재량 (최대) | 300 kg | 600 kg | 900 kg |
| 봇이 나를 노리는 정도 | 피함 | 보통 | 적극적 |
| 내가 받는 피해 | 50% | 80% | 100% |
| 한 번에 깎이는 최대 내구도 | 30% | 55% | 제한 없음 |
| 봇이 나를 먼저 노림 | 안 함 | 함 | 함 |
| 내가 받는 넉백 | 55% | 80% | 100% |
| 스폰 보호막 | 5초 | 3.5초 | 2.5초 |
| 가장자리 보조 | 강함 | 약함 | 없음 |

수치는 `index.html`의 `DIFFS`에서 바꿀 수 있습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| `W A S D` / 방향키 | 누른 방향으로 주행 (화면 기준) |
| `Space` | 니트로 부스트 (방향키 없이 눌러도 앞으로 돌진) |
| `Shift` | 드리프트 (미끄러지는 동안 니트로 충전) |
| 마우스 왼쪽 누르기 | 커서 쪽으로 주행 (오른쪽 버튼 = 니트로) |
| 터치 | 왼쪽 아래 고정 조이스틱, 오른쪽 아래 니트로/드리프트 버튼 (버튼 둘레가 니트로 잔량), 조이스틱을 잡은 채 다른 손가락으로 화면 누르기 = 니트로 |
| `M` | 소리 켜기/끄기 |

## 화면 방향

세로 전용입니다. 휴대폰을 가로로 들면 "세로로 돌려주세요" 안내가 뜨고 게임이 멈춥니다. 태블릿과 데스크톱은 가로도 그대로 됩니다.
앱으로 감쌀 때는 방향도 잠그세요: Android `AndroidManifest.xml`의 `android:screenOrientation="portrait"`, iOS `Info.plist`의 `UISupportedInterfaceOrientations`에 `UIInterfaceOrientationPortrait`만.

## 실행

```bash
npx serve games/scrap-derby   # 또는 index.html을 브라우저로 바로 열기
```

Three.js r128은 cdnjs에서, 폰트는 Google Fonts에서 불러옵니다.

## 튜닝 포인트

`index.html` 상단 상수: `ARENA_R`(아레나 반지름), `BOT_COUNT`, `BASE_SCRAP`, `SCRAP_KG`.
충돌 피해는 `collideCars()`, 주행 감각은 `driveCar()`(grip, turnRate, maxV), 봇 성향은 `createCar()`의 `ai.aggro / caution / playerBias`.
